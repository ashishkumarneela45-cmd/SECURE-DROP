Common questions

Yes, for practical purposes. Your file is encrypted with AES-256-GCM — the same standard used by banks and governments — before it leaves your browser. The decryption key is embedded in the link's #fragment, which browsers never send to servers. Even if someone hacked our server, they'd get only unreadable ciphertext.

The encrypted file is permanently deleted from our storage — both the .bin blob and the encrypted metadata. There is no recycle bin. Once the link expires or the download limit is hit, the data is gone and cannot be recovered by anyone, including us.

Adding a password means both the link AND the password are required. Send them via separate channels (e.g. link over email, password over SMS) for best security.
